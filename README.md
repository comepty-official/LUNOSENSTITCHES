# LUNOSENSTITCHES website

This is a self-contained, responsive website starter for **LUNOSENSTITCHES** — the brand name is intentionally written as one word throughout the project.

## Open locally

Open `index.html` directly in a browser, or serve this folder with any static file server.

## Included

- Responsive home page with brand navigation
- Scrub Design, Women's Wear, and Kids' Wear service areas
- Filterable gallery with full-screen image-style modal
- How-it-works process and customer testimonials
- Pricing cards with quote CTAs
- Ready-to-wear shop product cards
- Booking form with appointment details and inspiration upload field
- Contact form, business details, FAQ accordion, and footer
- Mobile navigation and lightweight interaction feedback

## Before publishing

Replace placeholder prices such as `₦___` and `₦XX,XXX` with final prices. Update the contact details, social links, product photos, and payment provider when those details are ready.

The uploaded reference image is included at `assets/reference-homepage.png` for visual direction.
